# Story 2.5: Admin Journal Access Interface

## Status
Done.

## Story
**As an** admin user,
**I want** a simple web interface to access and copy Ava's daily journal entries,
**so that** I can easily retrieve content for manual social media posting.

## Acceptance Criteria
1. An admin-accessible page displays a calendar or list view of all generated journal entries by date.
2. Clicking on any date expands to show the full journal entry for that day.
3. Each journal entry has a "Copy" button to copy the content to clipboard.
4. The interface is protected by admin authentication and not accessible to regular users.
5. Journal entries are displayed in read-only format with clear, readable styling.

const AdminRouteGuard = ({ children }: { children: React.ReactNode }) => {
  const { user, isAdmin, isLoading } = useAdminAuth();

  if (isLoading) return <AdminLoadingSpinner />;
  if (!user || !isAdmin) return <UnauthorizedAccess />;

};

**API Service Implementation Pattern**:
```typescript
// Journal API service functions
export const journalApi = {
  getEntries: (page?: number, limit?: number) =>
    authenticatedFetch('/api/admin/journal/entries', { params: { page, limit } }),
  getEntryByDate: (date: string) =>
    authenticatedFetch(`/api/admin/journal/entries/${date}`),
  updateEntryStatus: (id: string, status: string) =>
    authenticatedFetch(`/api/admin/journal/entries/${id}/status`, {
      method: 'PUT', body: { status }
    })
};
```

### Copy-to-Clipboard Implementation

**Browser API Integration**:
```typescript
// Copy functionality with fallback support
const copyToClipboard = async (text: string) => {
  try {
    await navigator.clipboard.writeText(text);
    showToast('Journal entry copied to clipboard!');
  } catch (err) {
    // Fallback for older browsers
    const textArea = document.createElement('textarea');
    textArea.value = text;
    document.body.appendChild(textArea);
    textArea.select();
    document.execCommand('copy');
    document.body.removeChild(textArea);
    showToast('Journal entry copied to clipboard!');
  }
};
```
