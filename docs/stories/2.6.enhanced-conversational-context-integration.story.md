### Integration Approach

**Step 1: Create Intelligent Context Selection Service**
- Build ContextualBackstoryService that analyzes user messages for keyword themes
- Implement content mapping: childhood/mother/family → childhood-memories.md, difficult/loss/grief → relevant trauma sections, positive/happy → positive-memories.md
- Add fallback to character-gist.md for general "tell me about yourself" queries
- Cache frequently accessed content to minimize file I/O

**Step 2: Token-Efficient Context Integration**
- Replace bulk journal loading with targeted backstory selection based on conversation context
- Include only recent simulation events (last 24 hours) to maintain living world feel
- Use global emotional state to influence conversation tone without excessive context
- Implement content size limits to stay within token budgets

**Step 3: Smart Content Selection Logic**
- Keyword matching: "childhood", "mother", "growing up" → childhood-memories.md
- Emotion-based: "sad", "difficult", "worst", "dreadful" → trauma-related content
- Positive queries: "happy", "best", "favorite" → positive-memories.md
- Relationship queries: "friends", "people", "relationships" → friend-character.md
- Default/general: "tell me about yourself", "who are you" → ava-character-gist.md

from dataclasses import dataclass

@dataclass
class ConversationContextConfig:
    """Centralized configuration for conversation context parameters"""

    # Simulation Event Context

    MAX_EVENTS_COUNT: int = 5

    # Backstory Content Limits
    MAX_BACKSTORY_CHARS: int = 8000  # ~2000 tokens

    # State Retrieval Windows
    GLOBAL_STATE_CACHE_TTL_MINUTES: int = 5
    SESSION_STATE_CACHE_TTL_MINUTES: int = 30

    # Context Selection Weights
    SIMULATION_EVENTS_WEIGHT: float = 0.6
    BACKSTORY_CONTENT_WEIGHT: float = 0.4

    # Performance Thresholds
    MAX_CONTEXT_PROCESSING_MS: int = 100
    CIRCUIT_BREAKER_FAILURE_THRESHOLD: int = 3
    CIRCUIT_BREAKER_TIMEOUT_SECONDS: int = 30

    # Content Type Priorities (higher = more important when selecting)

        "childhood_memories": 3,
        "positive_memories": 2,

**ContextualBackstoryService Implementation**:
```python
class ContextualBackstoryService:
    def __init__(self, config: ConversationContextConfig):
        self.character_service = CharacterContentService()
        self.config = config
        self.content_keywords = {
            "childhood": ["childhood", "child", "young", "mother", "mom", "family", "growing up", "when I was little"],
            "positive": ["happy", "best", "favorite", "wonderful", "amazing", "love", "joy", "good times"],
            "difficult": ["sad", "difficult", "hard", "worst", "dreadful", "tough", "struggle", "pain", "loss"],
            "relationships": ["friends", "friend", "people", "someone", "relationship", "social", "together"],
            "work": ["work", "job", "career", "office", "colleague", "professional", "deadline"],
            "general": ["yourself", "who are you", "tell me about", "what are you like"]
        }

    async def select_relevant_content(
        self,
        user_message: str,
        conversation_history: Optional[str] = None,
        max_chars: Optional[int] = None
    ) -> Dict:
        """Select relevant backstory content based on user message keywords"""
        message_lower = user_message.lower()
        selected_content = []
        content_types = []

        # Analyze for keyword matches
        if any(kw in message_lower for kw in self.content_keywords["childhood"]):
            selected_content.append(self.character_service.load_childhood_memories())
            content_types.append("childhood_memories")

        if any(kw in message_lower for kw in self.content_keywords["positive"]):
            selected_content.append(self.character_service.load_positive_memories())
            content_types.append("positive_memories")

        if any(kw in message_lower for kw in self.content_keywords["difficult"]):
            # Load trauma-related content (could be pillar memories or specific sections)
            selected_content.append(self.character_service.load_connecting_memories())
            content_types.append("connecting_memories")

        if any(kw in message_lower for kw in self.content_keywords["relationships"]):
            selected_content.append(self.character_service.load_friend_character())
            content_types.append("friend_character")

        # Default fallback to character gist for general queries
        if not selected_content or any(kw in message_lower for kw in self.content_keywords["general"]):
            selected_content.append(self.character_service.load_character_gist())
            content_types.append("character_gist")

        # Combine and limit content for token efficiency
        combined_content = "\n\n".join(filter(None, selected_content))

        # Use configurable character limit
        char_limit = max_chars or self.config.MAX_BACKSTORY_CHARS

        if len(combined_content) > char_limit:
            combined_content = combined_content[:char_limit] + "..."

        return {
            "content": combined_content,
            "content_types": content_types,
            "char_count": len(combined_content),
            "estimated_tokens": len(combined_content) // 4,  # Rough estimation
            "char_limit_used": char_limit,
            "selection_reasoning": f"Selected based on keywords and config limits: {content_types}"
        }
```
